# 教师使用说明：把视频整理成课程

> 视频相关的完整说明（媒体目录、扫描导入、章节划分、时长封面、权限与排查）见 **[video.md](video.md)**。

微课堂的三层结构是 **课程 → 章节（`group_name`）→ 课时（一条视频）**。
本文给出把视频变成课程的几种做法，以及常见疑问。

> **推荐路径（日常维护最省事）**：**课程管理新建课程 → 点进课程 → 绑定一个视频文件夹 → 点「扫描」**。
> 以后往那个文件夹里加视频，进课程再点一次「扫描更新」即可，不需要重新导入、也不会产生重复课时。

其他场景：视频在老师自己电脑上 → 用**做法二（网页直接上传）**；素材早就导进来了、当时还没建课程 → 用**做法四（批量改绑）**。

---

## 做法一（推荐）：课程 + 课程文件夹 + 扫描

适用于「素材已经在 NAS 的文件夹里」，也是长期维护最省心的方式——**课程和文件夹绑定一次，之后只维护文件夹**。

1. 进入 **课程管理**，点 **新建课程**；创建后会直接进入该课程的课时管理页；
2. 在「**课程文件夹**」卡片点 **选择文件夹**：
   - **媒体目录**：选一个已添加的宿主机目录（Docker/FPK 部署需先挂载进容器，见 `docs/deploy.md`）；
   - **子文件夹**：可留空表示「整个目录就是这门课程」，也可以填 `Java 程序设计` 这类子目录；点「浏览…」可以在目录树里选；
   - 一个文件夹只能绑定一门课程（避免两门课程抢同一批视频）；
3. 点 **扫描文件夹** —— 系统先给出预览（磁盘上几个视频、将新增几个课时、跳过几个、有没有文件已消失），确认后点导入；
   - 预览里可选 **章节怎么定**：
     - **按课程文件夹下的第一层目录（默认，推荐）**：素材常按「章 / 节 / 视频」多层放，只取第一层当章节列表才看得清
       （`第一章 有理数/3.1 乘方/xx.mp4` → 章节「第一章 有理数」）；
     - **按完整目录层级**：章节名取完整相对路径（`第一章 有理数/3.1 乘方`），适合需要精确到小节；
     - **不设章节**：全部归入「未分章」；
   - 换策略会**重新预览**，数字与章节名立刻跟着变；已扫描课时的章节名会按新策略同步（**手工课时的章节不受影响**）；
4. 结果：**子文件夹名 → 章节名**，文件名（去扩展名）→ 课时标题；课程文件夹自身的直接视频落在「未分章」；
5. 以后加了新课：把视频丢进对应子文件夹 → 回到该课程 → 点 **扫描更新**：
   - 只补新增的视频（已存在的跳过，不重复建课时）；
   - 新课时插在**同章节最后一条之后**，不会打乱你手工拖拽调好的顺序；
   - 若视频被从磁盘删掉，会列出「文件已不在磁盘上」的课时，勾选后可一并清理（**只清理扫描导入的，手工建/上传的绝不自动删除**）。

课时列表支持 **拖拽排序**（左侧 `⠿` 手柄拖动，或用行尾 `↑ ↓` 按钮），顺序按课程保存，
课程详情页与学习端都按这个顺序展示。拖完即自动保存，失败会回滚并提示。

**课程管理支持两种视图**：**平铺（默认）** 与 **列表**，点右上角「▦ 平铺 / ☰ 列表」切换，选择会被记住。
平铺视图里每张卡片直接显示课时数、已学完数以及「是否已绑定文件夹」，点卡片即可进入该课程。

## 做法二（最便捷）：网页直接上传

适用于「视频在老师自己的电脑/手机上」。上传在**两个地方**都能做，用的是同一个弹窗：

- **课程内**（推荐）：课程管理 → 点课程 → 课时管理里的 **⬆ 上传视频**，直接传到这门课程；
- **课程管理 → 全部课时 / 未归类课时** 里的 **⬆ 上传视频**：可在弹窗里选「**不归类** / **导入到已有课程** / **新建课程**」。

1. 打开上传弹窗；
2. 把视频**或整个文件夹**拖进虚线框，也可以点 **选择视频文件** / **选择整个文件夹**；
   - 拖入或选择整个文件夹时，浏览器会把目录结构一起带过来；
3. **章节怎么定**：**按文件夹结构自动（推荐）** / 不设章节 / 统一章节名；
   自动分章时会显示识别出来的章节名；
4. 点 **开始上传**，逐个显示进度；结束后列表里就有对应课时了（弹窗不会自动关闭，方便看失败项并重试）。

这条路径完全在网页里完成，视频存进服务自身的数据卷（媒体目录里会多出一个内置的
**「站内上传（课程视频）」**），**不需要宿主机挂载、也不需要运维介入**。适合老师自助；缺点是不便于和其他系统共享同一份素材库。

上限：单个视频默认 **2 GB**（`MC_MAX_VIDEO_MB` 可调）；反代部署时记得放开 `client_max_body_size`。

## 做法三：先导入，之后再归类（批量改绑）

适用于「视频早就导进来了，当时还没建课程」，或者上传时没选课程。

1. 进入 **课程管理**，切到 **未归类课时** 选项卡；
2. 勾选要归类的课时（表头复选框可全选）；
3. 出现批量操作条后点 **批量改绑到课程…**；
4. 在弹窗里选择 **目标课程**；
5. 可选填 **统一章节名** —— 留空则各自保留原章节；填了就把这批课时统一改成该章节；
6. 点 **确认改绑**。

改绑是**改归属、不复制数据**：课时、进度、刷题记录都跟随保留。
删除课程也**不会**删课时 —— 它们会回到「未归类课时」，可以在这里重新归类。

> 「全部课时」选项卡是跨课程的总览：可按课程筛选（含「未归类」）、按标题/章节/视频路径搜索
> （例如找出所有**空章节**的课时），也能勾选后批量改绑（含「移出课程（回到未归类）」）或删除。

## 外部平台的视频（嵌入 / 直链）

除了服务器上的本地文件，课时也可以挂**外部平台**的视频：新建 / 编辑课时时在「**视频来源**」里选。

| 来源                 | 存什么                       | 怎么播                                         | 典型场景                                             |
| -------------------- | ---------------------------- | ---------------------------------------------- | ---------------------------------------------------- |
| **本地视频**（默认） | 媒体目录 + 相对路径          | 站内 `/lessons/:id/video`，支持 Range 拖动续播 | NAS / 服务器上的课程视频（文件夹扫描出来的都是这类） |
| **嵌入播放**         | 平台播放器地址（iframe src） | 观看页用 `<iframe>` 内嵌播放                   | B 站、腾讯视频、YouTube 的「分享 → 嵌入代码」        |
| **外部直链**         | 视频文件地址（mp4 等）       | 观看页 `<video src>` 直接播                    | 视频放在别的服务器 / CDN / 对象存储                  |

需要知道的几件事（都直接影响能不能播）：

- **嵌入代码整段粘贴就行**：从平台复制的 `<iframe src="…">…</iframe>` 会被自动取出 `src`；
  `//player.bilibili.com/…` 这种协议相对地址会自动补成 `https://`（保存后列表里看到的是干净地址）。
- **外部视频不抽取时长/封面**：服务器拿不到文件，ffprobe 用不上（接口会明确拒绝而不是静默失败）。
- **外部视频不做「看完 80% 才解锁刷题」**：外部播放器不给可信进度，硬卡会导致永远刷不了题；
  观看页因此多一个「标记为已学完」按钮让学生自行确认。
- **能不能嵌入取决于平台**：平台若用 `X-Frame-Options` / `frame-ancestors` 禁止被嵌入，页面里就是空白。
  B 站、YouTube 允许外嵌；**超星学习通等课程视频通常不允许外嵌**，这类只能在原平台观看。
- **直链请用 mp4/webm**：HLS（`.m3u8`）在 Chrome/Edge 里无法直接播放（原生只支持 Safari）；
  另外很多 CDN 会校验 Referer 防盗链，直链在别的站点可能 403。
- 开启严格 CSP（`MC_CSP=1`）时，嵌入源放开的是 `https:`，直链视频也已放开 `https:`（勿再收紧 `media-src`）。

## 题目怎么批量导入导出（CSV / Markdown / Word）

题库管理页顶部即可完成，四种格式分工不同：

| 格式                     | 导入 | 导出 | 适合谁                                                                       |
| ------------------------ | ---- | ---- | ---------------------------------------------------------------------------- |
| **CSV**                  | ✅   | ✅   | 习惯 Excel 的老师：一列一个字段，方便批量校对、排序、查重                    |
| **Markdown（.md/.txt）** | ✅   | ✅   | 手写/让 AI 出题/贴进笔记软件：纯文本、可进版本库、导出的文件能再导入         |
| **Word（.docx）**        | ✅   | ✅   | 教研组用 Word 出卷、要打印发给学生；导出的 Word **配图内嵌**、单文件即可分发 |
| **模板**                 | —    | ✅   | 「CSV 模板」「Markdown 模板」两个按钮，照着填最省事                          |

**Markdown / Word 的写法**（两者规则完全一样，Word 是把正文抽出来按同一套规则解析）：

```text
### 1. 单选题
Java 中定义常量的关键字是？
A. const
B. final
C. static
D. define
答案：B
解析：final 修饰的变量为常量

### 2. 多选题
属于 Java 基本数据类型的有？
A、int
B、String
C、boolean
D、double
答案：ACD

### 3. 判断题
Java 是纯面向对象语言。
答案：错

### 4. 填空题
Java 程序的入口方法是 ___ 。
答案：main|Main

### 5. 填空题（多个空：按题目顺序用「；」分隔）
$2$ 的相反数是 ___ ，绝对值是 ___ 。
答案：-2；2

### 6. 简答题
简述面向对象三大特性。
答案：封装、继承、多态
```

- 写起来很宽松：题型行支持 `## 单选题`、`**多选题**`、`[判断题]`、`第 1 题 · 单选`，甚至直接写 `单选题`；
  也可以把题型写在题干开头，如 `【判断题】Java 是编译型语言。`；
- 选项支持 `A. x`、`A、x`、`A)x`、`A．x`、`（A）x`；**选项、答案、解析的先后顺序随意**；
- 判断题、填空题、简答题不需要选项；填空题多个可接受答案用 `|` 分隔（如 `main|Main`）；
- **填空题有多个空时**，答案按题目顺序用 `；` 分隔，例如题干「有理数 $2$ 的相反数是 ___ ，绝对值是 ___ 。」
  对应答案写 `-2；2`；某个空有多种写法时在**该空内部**用 `|`，例如 `\frac{3}{2}|1\frac{1}{2}；0.25`。
  学生在课后练习/考试里也按同样规则作答（输入框会提示「共 N 个空，用「；」分隔」），
  判分是**逐空比对**：空数不符或有一空不对，本题算错；
- 导入会**逐题校验**：失败的题会告诉你「第几题、原文第几行、为什么」，不影响其它题；能导入但有隐患的地方
  （例如题干里有图片链接）会单独列为「需要注意」。
- **图片**：导出 Word 会把已有配图**内嵌**；导入 Word 时**文档里的图片会自动存成题目配图**
  （支持 png/jpg/gif/webp/bmp；一题多图只保留第一张；不支持的格式会跳过并提示）。
  Markdown 里的图片链接仍**不会自动下载**（安全考虑），会提示你到题目编辑里单独上传。

导出还有「**Word 试卷（不含答案）**」按钮：不带答案解析，适合直接发给学生做。

## 知识点怎么导出（Markdown / Word）

知识点（课时下的讲义、链接、附件）也能导出成一份讲义：

- **整门课程**：课程课时管理页 → **「课程讲义（知识点导出）」** 卡片 → 「导出讲义 Markdown」/「导出讲义 Word」；
  内容按 **章节 → 课时** 组织：文本类知识点导出正文、链接导出可点链接、附件导出文件名（文件在课时页下载）；
- **单个课时**：课时行的「知识点」弹窗底部 → 「导出 MD」/「导出 Word」。

用途：Markdown 适合贴进笔记软件、交给 AI 改写或进版本库；Word 适合打印、发给学生或交给教研组继续补充。

## 视频时长与封面

课时列表里的**时长**和**封面**由后端自动抽取（ffprobe 取时长、ffmpeg 抽一帧做封面），
做法与飞牛「轻课堂」一致。两种触发方式：

- 导入/上传视频后**自动后台抽取**（不阻塞操作）；
- 在 **课程课时管理** 页点 **「抽取时长/封面」** 手动补齐历史课时（循环调用，直到处理完）。

若运行环境没有 ffmpeg/ffprobe，抽取会被跳过（不影响播放），提示会明确告知；
官方 Docker 镜像默认已内置 ffmpeg（可用 `--build-arg INSTALL_FFMPEG=0` 关闭以减小体积）。

## 观看完整性（为什么拖到最后不算看完）

系统除了记录播放位置，还按**观看区间**记录你真正看过的片段（与轻课堂的 `watch_intervals` 思路一致）：

- 每 15 秒、暂停、播放结束、拖动进度条时上报一次；
- 服务端把区间**去重合并**后再统计，跳过没看的部分不计时；
- 本地视频「看完 80% 解锁刷题」按**去重后的已看时长 / 视频总时长**判定；
- 区间覆盖 ≥95% 会自动标记为「已学完」。

观看页会同时显示「观看进度（位置）」与「实际看过（区间）」，两者不一致说明中间有跳过。

## 常见疑问

**Q：为什么我导入后看到「扫描完成：没有新视频」或「已导入 0 个，跳过 30 个」，课程里还是空的？**
因为扫描/导入只负责「新增」，遇到已存在的同路径视频会跳过（防止重复建课时）。想让它们进课程，用**做法三**的批量改绑
（课程管理 → 未归类课时）；如果这些课时已经挂在**别的**课程下，直接在目标课程里绑定该文件夹再扫描，会自动**收编**过来。

**Q：课程文件夹和批量改绑该用哪个？**
长期维护用**做法一**（绑定文件夹 + 扫描）：新增视频只需丢进文件夹再扫一次；临时整理历史数据用**做法三**（批量改绑）。
两者可以混用——扫描时遇到同路径但挂在别门课程下的课时，会自动**收编**到本课程（不会重复建课时）。

**Q：一个文件夹里有子文件夹，会怎么归类？**
子文件夹名 → 章节名；再深一层也会各自成为章节。文件名（去掉扩展名）→ 课时标题。

**Q：导入会不会把视频复制一份？**
不会。数据库里只记录「媒体目录 + 相对路径」，源文件始终留在原处；播放时按 Range 流式读取。

**Q：重复导入同一个文件夹安全吗？**
安全，默认跳过重复项。同一路径视频只对应一个课时。

**Q：改绑错了怎么办？**
再勾选一次改绑到正确课程即可（删除课程也不会删课时，课时会回到「未归类课时」，在那里重新归类）。

**Q：视频播放提示「文件不可读：请确认应用运行用户对媒体目录有读权限」？**
容器以非 root 运行，而 NAS 上的视频属主可能是别的用户且权限为 `700`。解决方式见 `docs/deploy.md` 的「媒体目录权限」一节（用 `--user <媒体属主uid>` 运行，或放开读权限）。

**Q：章节能不能后期改名？**
可以，两种方式：编辑单个课时时改「章节」字段；或勾选一批课时用批量改绑、填统一的章节名（只能整批统一，不能批量替换其中一部分）。
