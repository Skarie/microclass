# 视频挂载完全指南（把视频变成课时）

本篇讲清楚三件事：**视频放哪里**、**后台怎么认到它**、**出问题怎么查**。
三种挂载方式按场景选一种即可，也可以混用。

| 方式                            | 适合场景                           | 优点                           | 代价                                 |
| ------------------------------- | ---------------------------------- | ------------------------------ | ------------------------------------ |
| **A. 媒体目录扫描导入**（推荐） | 已有整理好的视频文件夹、成批上线   | 批量、可重复扫描、章节自动划分 | 需要宿主机放文件 + 配一个环境变量    |
| **B. 网页直接上传**             | 少量视频、临时补录、没有宿主机权限 | 全在界面里完成                 | 受上传大小限制、占容器磁盘           |
| **C. 外链 / 嵌入**              | 视频已在 B 站 / 腾讯 / 自建 CDN    | 不占服务器磁盘                 | 依赖第三方（可能被限速、广告、失效） |

---

## 0. 先理解三个词

```
媒体目录（MC_MEDIA_ROOTS）  →  课程文件夹（绑定某个媒体目录下的子路径）  →  课时（一个视频 = 一条课时）
```

- **媒体目录**：宿主机上的一个绝对路径（例如 `/volume1/media/数学`）。它是白名单——只有登记过的目录，后台才能读取。
- **课程文件夹**：某门课程「绑定」媒体目录下的一个子路径（例如 `七年级上册`）。绑定后，该子路径下的视频才能被扫进这门课。
- **课时**：视频在平台里的记录。两种来源：
  - `source = folder`：由扫描生成，**跟随文件夹变化**（文件夹里删了文件 → 可被清理；章节名跟随文件夹）；
  - `source = manual`：手工创建或网页上传，**永不被扫描自动删除**（文件丢了只提示）。

---

## 方式 A：媒体目录扫描导入（推荐）

### A1. 在宿主机整理视频目录

约定：**一级目录 = 章节**（默认规则）。

```
/volume1/media/数学/七年级上册/            ← 课程文件夹（课程绑定到这一层）
├── 第一章 有理数/                          ← 章节（chapterMode=first 时取这一层）
│   ├── 1.1 正数和负数.mp4
│   ├── 1.2 有理数.mp4
│   └── 1.3 有理数加减法.mp4
├── 第二章 整式的加减/
│   ├── 2.1 整式.mp4
│   └── 2.2 整式的加减.mp4
└── 复习课-期末考试串讲.mp4                  ← 直接放在课程文件夹根目录 → 归入「未分章」
```

命名建议：

- 用**序号开头**，平台按**自然序**排序（`2. xxx` 排在 `10. xxx` 前，不会像字符串那样把 10 排到 2 前面）。
- 文件名去掉扩展名后就是课时标题；`第一章 有理数` 这类目录名会成为章节名。
- 支持常见容器/编码（`.mp4 / .mkv / .mov / .webm / .avi` 等；浏览器不能直接播放的封装，请先转成 H.264 + AAC 的 MP4）。
- 章节层级不必固定：素材如果按「章/节/视频」三层放，可用 `chapterMode` 调整章节取名规则（见下文）。

### A2. 配置媒体目录（环境变量）

`MC_MEDIA_ROOTS` 是一个 **JSON 数组**，每项含 `id / name / path`：

```bash
MC_MEDIA_ROOTS='[{"id":"math7","name":"数学·七年级","path":"/media/math7"}]'
```

- `id`：稳定标识（改名字不影响已导入的课时），建议用英文/数字。
- `name`：后台显示名。
- `path`：**容器内的路径**（Docker 部署时要用 `-v` 把这个宿主机目录挂进来，见 A6）。

多个目录就写多组，例如：

```bash
MC_MEDIA_ROOTS='[
  {"id":"math7","name":"数学·七年级","path":"/media/math7"},
  {"id":"chem9","name":"化学·九年级","path":"/media/chem9"}
]'
```

> 想临时试一下：也可以不配环境变量，直接在后台「课程管理 → 媒体目录」里登记路径（登记是否被允许由服务端校验；生产建议统一用环境变量管理）。

### A3. 确认后台能看到这些目录

1. 用管理员登录 → 左侧 **课程管理**。
2. 切到 **媒体目录** 标签页 → 应看到 A2 里登记的目录及其文件数。
3. 点进目录可**浏览**子路径，用来确认路径写对了。

看不到 / 数量为 0 → 直接跳到文末「排错」第 1、2 条。

### A4. 给课程绑定文件夹

1. 在 **课程** 标签页找到目标课程 → 点卡片进入 **管理课时**（或直接点课程名）。
2. 在课时管理页点 **绑定视频文件夹** → 选媒体目录 → 选子路径（例如 `七年级上册`）。
3. 绑定后页面会显示该文件夹的完整来源，方便核对。

### A5. 先预览、再正式扫描

课时管理页的扫描支持两种模式：

- **预览扫描（dry run）**：只列出「会新增 / 会更新 / 会清理」的清单，**不动数据库**。建议第一次一定先预览。
- **正式扫描**：按清单落库。

扫描时可选的几个行为：

| 选项            | 含义                                                                                             | 建议                                                    |
| --------------- | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------- |
| `chapterMode`   | 章节名规则：`first`=取课程文件夹下**第一层**目录（默认）；`full`=取完整相对路径；`none`=不设章节 | 素材是「章/节/视频」时用 `full`；不想要章节用 `none`    |
| `removeMissing` | 磁盘上已消失的 `folder` 课时是否清理                                                             | 确认是「真删了」再开；`manual`（上传/手工）课时不受影响 |
| `onDuplicate`   | 同一路径已在别门课时：`assign`=收编到本课程；`skip`=跳过                                         | 换绑课程时用 `assign`（默认），只想新增时用 `skip`      |

扫描的**幂等性保证**：

- 已存在的课时不会重复创建；
- **新课时插到「同章节最后一条之后」**，所以你手工拖拽调好的顺序不会被下一次扫描打乱；
- 重复扫描只做增量，不会重建整门课。

### A6. Docker 部署时别忘了挂载目录 + 权限

```bash
docker run -d --name microclass \
  -p 8091:8091 \
  -e MC_ADMIN_PASS='强密码' \
  -e MC_MEDIA_ROOTS='[{"id":"math7","name":"数学·七年级","path":"/media/math7"}]' \
  -v microclass-data:/app/data \
  -v /volume1/media/数学/七年级上册:/media/math7:ro \
  microclass:latest
```

**权限是最常见的坑**：容器里的进程用户必须能**读**这些视频文件。

```bash
# 方案 A（推荐）：让容器用媒体属主身份运行
id -u <媒体属主>            # 例：1000
#   compose 里写 user: "1000:1000"，并把 /app/data 卷的属主也改成同一用户
sudo chown -R 1000:1000 /volume1/docker/microclass/data

# 方案 B：给媒体目录放开读权限（同机其他用户也可读，自行评估）

# 验证：以容器内用户身份试读一个视频，能输出字节数就 OK
docker exec -it microclass sh -c 'wc -c /media/math7/第一章\ 有理数/1.1\ 正数和负数.mp4'
```

## 方式 B：网页直接上传

适合没有宿主机权限、或临时补几节课时。

1. **课程管理 → 课程 → 管理课时**，或 **全部课时 / 未归类课时** 标签页（三处都能上传）。
2. 点 **上传视频**，选择文件、填写**章节**（可新建或选已有），提交。
3. 上传完成后课时即出现在列表里，`source = manual`。

注意：

- 上传上限由 `MC_MAX_VIDEO_MB` 控制（默认 2048 MB）。**改完要重启服务**才生效。
- 上传的视频落在 `MC_DATA_DIR` 下（默认 `/app/data`）→ **备份数据目录就等于备份了这些视频**。
- 需要「时长 / 封面」时，请确保容器/宿主机里有 `ffprobe`、`ffmpeg`（见文末第 5 条）。
- 同一个文件重复上传不会自动去重，请用「全部课时」搜索确认。
- 上传走的是分片请求，中间失败可以重试；**千万不要在上传过程中重启服务**（会留下不完整文件，删掉该课时重传即可）。

## 方式 C：外链 / 嵌入（B 站、腾讯、自建 CDN）

1. 课时编辑里把**视频来源**切成外链/嵌入，粘贴播放地址或平台提供的 **iframe 嵌入代码**。
2. 保存后到观看页播放，确认能出画面。

注意事项：

- **HTTPS 混合内容**：平台如果是 `https://`，外链视频也必须是 `https://`，否则浏览器会拦截。
- **防盗链**：部分平台校验 Referer，可能需要改用其官方嵌入方式，或把视频放到自己的对象存储/CDN。
- **进度记录**：外链播放时平台仍会按播放器事件记录进度，但第三方播放器的行为差异较大，「断点续播」体验不如本地文件稳定。
- 外链课时不占用服务器磁盘，也**不参与**媒体目录扫描的清理逻辑。

## 章节自动划分规则（`chapterMode`）

以课程文件夹为基准（`课程文件夹/...`）：

| 目录结构                             | `first`（默认） | `full`                         | `none` |
| ------------------------------------ | --------------- | ------------------------------ | ------ |
| `第一章 有理数/1.1 正数和负数.mp4`   | 第一章 有理数   | 第一章 有理数                  | 未分章 |
| `第一章 有理数/1.1 正数和负数/a.mp4` | 第一章 有理数   | 第一章 有理数 / 1.1 正数和负数 | 未分章 |
| `复习课.mp4`（根目录）               | 未分章          | 未分章                         | 未分章 |

- 章节名**跟随文件夹**：把文件从一个章节目录挪到另一个，重扫后课时章节会同步更新。
- 手工改过章节名的 `manual` 课时不会被扫描覆盖。

## 时长与封面

平台会用 `ffprobe` / `ffmpeg` 读取时长并抽一帧做封面：

- 未配置也能用，只是**时长显示为空、封面为占位图**；
- 配置方式：`MC_FFPROBE_PATH` / `MC_FFMPEG_PATH`（默认从 PATH 里找 `ffprobe` / `ffmpeg`）；
- Docker 镜像里已包含 ffmpeg（构建参数可选国内源，见部署手册）；
- 个别损坏或特殊编码的文件探测失败，只会缺少时长/封面，不影响播放。

---

## 播放机制（为什么体验是这样）

- 视频通过 **HTTP Range** 流式返回（`GET /api/v1/lessons/:id/video`），所以能**拖动进度条**、边下边播；
  → 反向代理**不要**把响应整体缓冲（Nginx 需 `proxy_buffering off`，见部署手册）。
- 平台记录**最远观看位置**用于断点续播；把进度条直接拖到最后**不算看完**（防止「拖到底刷完」）。

## 排错

| 现象                   | 原因                                                           | 处理                                                                 |
| ---------------------- | -------------------------------------------------------------- | -------------------------------------------------------------------- |
| 媒体目录里文件数 0     | `path` 写的是宿主机路径而不是**容器内路径**；或忘了 `-v` 挂载  | 用 `docker exec -it microclass ls /media/math7` 确认容器内能看到文件 |
| 扫描不到文件           | 路径不在白名单；扩展名不支持；文件名是临时文件（`.part/.tmp`） | 浏览器核对路径；换成常见视频扩展名                                   |
| 播放 403「文件不可读」 | 容器用户对媒体目录没有读权限                                   | 见 A6（chown 或 let container user match）                           |
| 播放 404               | 磁盘上文件已删/改名，但课时还在                                | 重扫（可开 `removeMissing` 清理 `folder` 课时）                      |
| 能播放但拖不动进度条   | 反向代理缓冲了响应                                             | 反代加 `proxy_buffering off`，并透传 `Range`/`Accept-Ranges`         |
| 上传失败               | 超过 `MC_MAX_VIDEO_MB`；或磁盘满                               | 调大限制并重启；清理 `MC_DATA_DIR`                                   |
| 时长/封面为空          | 没有 ffprobe/ffmpeg 或文件探测失败                             | 配置 `MC_FFPROBE_PATH`/`MC_FFMPEG_PATH`                              |
| 同一视频出现两条课时   | 手工建过、又在文件夹里被扫描到（或换绑课程时用了 `assign`）    | 「全部课时」搜索标题 → 删掉多余的；下次扫描用 `onDuplicate: skip`    |
| 扫描把手工课时删了？   | 不会：`manual` 课时永不自动删除                                | 若确实消失，检查是否手工删除或换了数据库                             |

## 最小可用流程（照着做一遍）

```text
1) 宿主机放视频：/volume1/media/math7/七年级上册/第一章 有理数/1.1 正数和负数.mp4
2) 启动容器（示例见 A6），环境变量：
     MC_MEDIA_ROOTS=[{"id":"math7","name":"数学·七年级","path":"/media/math7"}]
   挂载：-v /volume1/media/math7:/media/math7:ro
3) 后台 → 课程管理 → 媒体目录：确认能看到 math7（文件数 ≥1）
4) 新建课程「初中数学·七年级上册」→ 管理课时 → 绑定视频文件夹：math7 / 七年级上册
5) 预览扫描 → 确认清单 → 正式扫描（chapterMode=first）
6) 回到课时列表：应看到「第一章 有理数」下的「1.1 正数和负数」
7) 学生端打开课程 → 观看页能播放、能拖动、退出再进能续播
```
