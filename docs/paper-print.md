# 试卷预览与打印（A4 / A3）

> 目标：组好卷之后能**在管理端看题、看整卷**，并且**直接打印出能发的纸质卷**（A4/A3，可含答案、答题卡、密封线）。

## 1. 为什么是「服务端出 HTML」而不是前端渲染后打印

- 打印要在任何浏览器上出正确版式，不能依赖前端脚本跑完；
- 题库里数学题大量使用 `$...$` LaTeX，**必须在服务端用 KaTeX 渲染成 HTML**，
  否则打印出来是 `\frac{1}{2}` 这种源码；
- `@page { size: A4 }` / `size: A3` 决定纸张，浏览器「另存为 PDF」也照它走
  （验收脚本会用 Chromium 按 CSS 纸张尺寸出 PDF 并校验 MediaBox）。

## 2. 接口

| 方法 | 路径                          | 权限        | 说明                                          |
| ---- | ----------------------------- | ----------- | --------------------------------------------- |
| GET  | `/exams/:id/paper.html`       | 教师/管理员 | 可打印试卷（HTML，直接浏览器打开）            |
| GET  | `/paper-assets/katex.min.css` | 公开        | 自托管 KaTeX 样式（离线也能打印，不依赖 CDN） |
| GET  | `/paper-assets/fonts/:file`   | 公开        | KaTeX 字体                                    |

查询参数：

| 参数          | 取值                            | 说明                                 |
| ------------- | ------------------------------- | ------------------------------------ |
| `size`        | `A4`（默认）/ `A3`              | 纸张                                 |
| `orientation` | `portrait`（默认）/ `landscape` | 方向                                 |
| `columns`     | `1`（默认）/ `2`                | 分栏（A3/横排常用双栏）              |
| `answers`     | `1`                             | 附答案与解析（教师卷）               |
| `sheet`       | `1`                             | 附答题卡（独立一页，含选择题涂卡格） |
| `seal`        | `1`                             | 左侧密封线（学校/班级/姓名/考号）    |
| `scoreBox`    | `0`                             | 不显示每题后分值                     |
| `print`       | `1`                             | 载入后自动弹打印对话框               |
| `fillLines`   | `1..5`                          | 填空题作答横线行数                   |
| `answerSpace` | `15..120`（mm）                 | 解答题留白高度                       |

## 3. 版式（对齐常见真卷）

```
学校名（站点名，居中，小字）
        试卷标题（居中，加大）
（满分 100 分　考试时间 60 分钟　共 31 小题）
班级：____ 姓名：____ 学号：____ 得分：____

一、单选题（本大题共 10 小题，每小题 3 分，共 30 分）
1. 题干（公式已排版）  （3 分）
   A. 选项甲    B. 选项乙    C. 选项丙    D. 选项丁
2. …
二、填空题（本大题共 8 小题，每小题 4 分，共 32 分）
11. 计算：____（作答横线）
…
```

- 题号**跨大题连续**；填空题给作答横线，解答题给留白框；
- 判断题给「（　　）」作答位；
- 可选：左侧竖排密封线、独立一页答题卡（涂卡格 + 主观题作答区）、每题分值标注；
- 含答案时在每题下方给出 `【答案】/【解析】` 灰底块，方便出教师卷。

## 4. 管理端入口

**考试列表每行**（不用先进组卷页）：

- **预览试卷**：新窗口打开 A4 版式的可打印试卷（默认不含答案）；
- **打印**：新窗口打开并自动弹打印对话框（可另存为 PDF）。

选中一场考试 →「组卷」页（三栏工作台）：

- 卷内每道题有 **看题**（完整题面 + 选项 + 答案/解析，可一键隐藏答案）；
- 挑题区每道题也有 **看题**（决定要不要加入前先确认）；
- **预览整卷**：按打印版式嵌在弹窗里（含答案/答题卡/密封线可即时切换）——所见即所印；
- **打印 / 导出 PDF**：选纸张（A4/A3）、方向、分栏、含答案、答题卡、密封线 → 打开打印视图，
  浏览器里直接打印或「另存为 PDF」。

> 抽题范围：组卷页左栏「挑题范围」（本课程 / 全库所有题）同时决定「智能组卷」的范围，
> 右栏「智能组卷」会显示当前范围。默认只抽**这场考试所属课程**的题，
> 只有明确切到「全库所有题」（或接口传 `scope=all`）才会跨课程抽题。

## 5. 验收方式（真机）

`build/evo4-verify-paper-print.mjs`：

1. 打印页各选项生效（A4/A3、横竖版、双栏、答案、答题卡、密封线、自动打印）；
2. 公式确实是 KaTeX 渲染（页面里 `<span class="katex">`，正文无 `$…$` 残留）、图片是可达 `<img>`；
3. KaTeX 样式与字体自托管可访问；
4. **真出 PDF**：Chromium 按 CSS 纸张打印，校验页面里公式渲染完成、KaTeX 字体已加载、
   并**读取 PDF 的 MediaBox 验证纸张**（A4 = 8.27×11.69 英寸、A3 横向 = 16.54×11.69 英寸）。
