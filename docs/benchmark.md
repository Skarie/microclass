# 对标主流产品：能力矩阵与差距清单

> 目的：不再凭"感觉"调界面，而是**把主流在线学习产品的能力逐项对照我们的实现**，
> 得到客观差距与优先级。方法：① 公开产品形态与交互惯例；② 逐项 grep 本项目代码验证是否具备。

## 3. 差距清单与优先级

### P0（本轮已做）

1. **播放器倍速 + 快捷键 + 播完自动下一节** —— 学习页最常被吐槽"不如主流"的三点，已完成。

### P0（建议下一轮）

2. **全局搜索**：顶部搜索框/命令面板，跨"课程 · 课时 · 题库 · 题目 · 试卷"检索。
   主流产品都有（学习通、MOOC、Coursera），目前只有页内搜索，找东西必须记住在哪一页。
3. **移动端走查**：以 390×844 视口逐页检查（观看页、课程详情、题库、考试），
   重点：视频区域高宽比、横向溢出、按钮热区、表格转卡片列表。

### P1

4. **课时级"上一节/下一节"常驻导航**（目前只在播完时出现倒计时）。
5. **课程详情页的"目录 + 简介 + 讲师/信息"三段式**核对与补齐（对齐 MOOC/学习通）。
6. **学习报告页**（周/月维度：学习时长、完成课时、正确率趋势）——主流产品都有"我的学习"。
7. **站内通知**（考试发布、作业截止、错题提醒）。

### P2

8. 视频清晰度切换与画中画（原生控件已支持，若要接入 CDN/多码率再评估）。
9. 弹幕/讨论区（教学场景可选，默认关闭）。

## 4. 本轮已落地的对标项（播放器）

| 交互                           | 实现             | 细节                                       |
| ------------------------------ | ---------------- | ------------------------------------------ |
| 倍速 0.75 / 1 / 1.25 / 1.5 / 2 | 播放器下方按钮组 | 选择记在 `localStorage`，下次自动应用      |
| 空格 / k                       | 播放暂停         | 输入框聚焦时不抢键                         |
| ← →                            | 快退 / 快进 5 秒 | 边界收在 0 与时长之间                      |
| f / m                          | 全屏 / 静音      | 用原生 Fullscreen API                      |
| < > 或 , .                     | 降/升一档倍速    | 与主流播放器一致                           |
| 播完自动下一节                 | 5 秒倒计时横幅   | 可「立即播放」或「取消」；无下一节则不出现 |

**安全边界**：快捷键**只在播放器进入视口且在非输入状态时**接管 —— 否则会抢走页面空格滚动，
这属于"为了炫技牺牲可用性"，主流播放器（YouTube/B 站）也是这么收敛的。
