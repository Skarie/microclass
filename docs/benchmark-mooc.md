# 对标中国大学 MOOC：设计语言 · 页面骨架 · 功能清单 · 落地计划

> 对标对象：[中国大学 MOOC（icourse163.org）](https://www.icourse163.org/)，高教社 × 网易。
> 资料：官方站点结构与页脚、[《中国大学MOOC的产品分析报告》](https://m.163.com/dy/article/DCS29O6B0511805E.html)、
> 各高校发布的 MOOC 教师/学生使用手册（章节测验、考核计分、讨论区、证书等）。
> 本文逐项对照本项目实现，给出「已有 / 缺 / 怎么做」。

---

## 一、它的定位与信任结构（先说"气势"从哪来）

MOOC 官方一句话定位：

> 由高教社联手网易推出，让每一个有提升愿望的用户能够学到中国知名高校的课程，**并获得认证**。

拆开看，这句话里有四层"信任状"，也是它首页气势的来源：

| 层次             | 它怎么表达                           | 我们能不能有                    |
| ---------------- | ------------------------------------ | ------------------------------- |
| **机构背书**     | "高教社联手网易"、"与 180+ 高校合作" | 可以：写清平台归属与建设方      |
| **供给方权威**   | 课程来自名校名师，课程卡上直接标学校 | 可以：课程可挂"机构/教研组"字段 |
| **成果可视化**   | "并获得认证"（证书）                 | 可以：结课证明                  |
| **用户价值主张** | "让每一个有提升愿望的用户能够学到"   | 已有：「看的每一分钟，都算数」  |

**结论**：气势 ≠ 大图轮播，而是「谁办的 + 谁提供的 + 学完能拿到什么」这三句话是否清楚。
我们首页现在的三个信任要素是**数据带**（真实统计），缺的是**办学者与成果**。

## 二、设计语言对照

| 维度     | 中国大学 MOOC                               | 本项目现状                                 | 动作                         |
| -------- | ------------------------------------------- | ------------------------------------------ | ---------------------------- |
| 主色     | 青绿色系（网易系），白色底、浅灰分区        | 珊瑚橙 + 松石青点缀                        | 已成型，不动                 |
| 首页结构 | 搜索 → 分类入口 → **卡片网格** → 分栏目推荐 | 主视觉 → 数据带 → 金刚区 → 卡片网格 → 分组 | 已对齐                       |
| 课程卡   | 16:9 封面 + 课名 + 学校 + 状态              | 16:9 封面 + 分类角标 + 课名 + 课时/进度    | 已对齐（缺"学校/机构"）      |
| 分区方式 | 大块浅灰背景 + 白色卡片                     | 白底 + 卡片投影                            | 可接受（我们的设计语言更轻） |
| 章节呈现 | 列表 + 序号 + 时长 + 任务标记               | 章节/课时列表 + 拖拽排序                   | 已对齐                       |
| 页脚     | 友情链接 / 关于我们 / 帮助 / 备案 / 版权    | 三列 + 版本与版权行                        | 已对齐（缺备案与法务链接）   |

## 三、信息架构对照

**MOOC 一级导航（Web/App）**：首页 · 全部课程 · **我的课程** · 账号

| MOOC                                                          | 本项目                                   | 差距             |
| ------------------------------------------------------------- | ---------------------------------------- | ---------------- |
| 首页（推荐/分类/卡片）                                        | 课程大厅                                 | 已对齐           |
| 全部课程（列表 + 弹出式分类 + 筛选）                          | 大厅的筛选 + 卡片/列表切换               | 已对齐           |
| **我的课程**（在学 / 已学完 / 收藏）                          | 大厅"继续学习"主推块 + "只看收藏/未学完" | **缺独立聚合页** |
| 账号（关注/粉丝、已学时长、已学课程、参与讨论、**证书列表**） | 个人中心（等级、学习时长）               | 缺证书、讨论记录 |

## 四、课程内容页：MOOC 的 Tab 结构

MOOC 的课程内容页是 **公告 · 课件 · 考核 · 讨论** 四个 Tab（默认"课件"），
每一 Tab 用**列表**呈现，再点进内容页。这是它"像一个课堂"的关键。

| Tab      | MOOC 内容                             | 本项目                        | 差距                      |
| -------- | ------------------------------------- | ----------------------------- | ------------------------- |
| **公告** | 教师发布的开课/作业/考试通知          | ❌ 无                         | **缺（易做）**            |
| **课件** | 章节 → 视频/文档                      | ✅ 章节/课时/观看页           | 已对齐                    |
| **考核** | 章节测验、作业、互评、考试 + 截止时间 | ✅ 课后练习、组卷考试、成绩单 | 已对齐（缺截止时间/提醒） |
| **讨论** | 主题帖 + 回复 + 老师答疑              | ❌ 无                         | **缺（核心，较大）**      |

MOOC 的"上课"流程（其产品文档原话）：
**查看课程公告 → 学习课程材料 → 完成考核任务 → 考核评价（+ 交流讨论）**。
我们目前只有中间的"学习材料 + 考核"，两头（公告、讨论）是空的。

## 五、功能清单：它有什么 / 我们有什么 / 怎么做

### A. 已有且对齐

章节课时、断点续播、观看完整性（我们有，它没有）、课后练习解锁、题库组卷考试、成绩单、
收藏课程（它 2018 年还列为"迭代方向"，我们已经有了）、笔记、知识点、深浅色、无障碍。

### B. 缺 —— 建议按此顺序做

| #   | 功能                        | MOOC 的做法                                 | 我们怎么做                                                   | 量级   |
| --- | --------------------------- | ------------------------------------------- | ------------------------------------------------------------ | ------ |
| 1   | **课程公告**                | 公告 Tab，教师发布，学生首页/学习页可见     | 课程公告表 + 发布接口 + 课程页/观看页展示                    | 小     |
| 2   | **后退 10~15 秒**           | 播放器按钮（用户强烈反馈要的）              | 播放器加「后退 15 秒」按钮（我们已有 ←→ 5 秒快捷键）         | 极小   |
| 3   | **我的课程聚合页**          | 一级导航项：在学 / 已学完 / 收藏            | 新增 `/my-courses`：在学（含下次学习位置）、已学完、收藏三组 | 小     |
| 4   | **学习提醒**                | 可自定义提醒时间（Coursera 模式）+ 截止时间 | 考试/练习截止 + 站内提醒（先做站内，不发邮件）               | 中     |
| 5   | **讨论区**                  | 课程下主题帖 + 回复 + 教师参与              | 帖子表（课程/课时维度）+ 回复 + 教师标记                     | 中     |
| 6   | **结课证明/学习记录**       | 证书列表（账号页）                          | 完成度达标 → 生成可打印的结课证明页                          | 中     |
| 7   | **字幕文本 + 快捷保存笔记** | 单独字幕 + 一键存当前时间点笔记             | 我们已有"时间点笔记"，缺字幕（需 srt/vtt 导入与展示）        | 中     |
| 8   | **专项课程 / 学习路径**     | 4–5 门课组成系列，从入门到进阶              | 课程集合（专题）字段 + 专题页                                | 大     |
| 9   | **音频模式**                | 锁屏听音频                                  | 同一 `<video>` 的 audio-only 播放入口                        | 小     |
| 10  | **弹出式分类与筛选**        | 课程列表页的弹出目录/筛选器                 | 我们已有分类金刚区 + 下拉筛选                                | 已对齐 |

### C. 我们领先的地方（别丢）

- **观看完整性**：记录实际观看区间，防止"拖到最后"（MOOC/多数平台只记进度条）
- **题库与组卷**：双向细目表、平行卷、卷内替换、Word/PDF 打印
- **无障碍**：axe 规则进 CI、键盘可达、语义化结构
- **本地优先**：媒体目录扫描、断点续播、数据自托管

## 六、落地计划（分批）

### 第一批（结构补齐，小步可验证）

1. 课程公告（发布 + 展示）
2. 播放器「后退 15 秒」按钮
3. /my-courses 我的课程聚合页

### 第二批（课堂感）

4. 讨论区（课程/课时维度，教师可标记）
5. 课程内容页 Tab 化：公告 · 课件 · 考核 · 讨论

### 第三批（成果与提醒）

6. 结课证明
7. 截止时间 + 站内提醒
8. 字幕导入与展示

### 第四批（体系化）

9. 专题/学习路径
10. 账号页补：已学课程、讨论记录、证书列表
